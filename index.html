Install in 30 Seconds

Requires Fabric Loader 0.16.9+ for Minecraft 1.21.8

1

Install Fabric

Download and run the Fabric installer for Minecraft 1.21.8. Select the Fabric Loader 0.16.9+ and install the client.

2

Build the Mod

Run ./gradlew build in the MaceBurst project directory. Find the output at build/libs/MaceBurst-1.0.0.jar.

3

Drop Into Mods Folder

Copy MaceBurst-1.0.0.jar into your .minecraft/mods/ folder. Also ensure fabric-api-0.112.0+1.21.8.jar is in there.

4

Launch & Dominate

Launch Minecraft 1.21.8 with the Fabric profile. Pick up a mace, jump off something high, aim near a player, and watch the combo chain begin.
